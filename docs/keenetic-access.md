# Улей из интернета через Keenetic

Цель: открыть интерфейс Улья с телефона откуда угодно по обычному адресу с настоящим HTTPS, без VPN, и при этом
не сделать из него лёгкую мишень. Схема: KeenDNS на роутере держит сертификат Let's Encrypt и пересылает запросы
на отдельный вход Улья, порт **8088** на RPi. Через этот вход видны только интерфейс и его api: регистрация шершней,
загрузка фото, OTA, `/ca.crt` и документация API снаружи закрыты (404).

## Что защищает вход

- **Пароль + код из Telegram на новом устройстве.** Устройство, с которого уже входили с кодом, Улей запоминает
  (Настройки → «Запомненные устройства»); с него хватает пароля. С любого другого бот присылает 6 цифр,
  в сообщении видно браузер и IP. Код живёт 10 минут, пять неверных — и нужно войти заново.
  Приложение-аутентификатор (TOTP) работает как запасной вариант, если оно включено.
- **Снаружи без второго фактора не войти.** Пользователь без привязанного Telegram и без TOTP получит отказ
  «сначала привяжите Telegram». Дома, в своей сети, он войдёт по паролю, как раньше.
- **Паузы после неверных паролей и кодов.** 5 подряд — вход с этого устройства приостановлен на час, 10 — на сутки.
  Считается по устройству: если с чужого компьютера подбирают пароль, ваш телефон продолжает входить. Устройство,
  которое Улей ещё не знает, считается по IP. Когда пауза начинается, владельцу логина приходит предупреждение в Telegram.
- **Забытый пароль** — «Забыли пароль?» на странице входа: на почту из настроек приходит пароль восстановления
  (8 символов, 30 минут, одно использование). После смены пароля все запомненные устройства забываются, и следующий
  вход потребует код из Telegram: одной почты для входа мало.
- Сессия — cookie `HttpOnly`, `Secure`, `SameSite=Strict`, на 30 дней. Снаружи только HTTPS (HSTS).

## Что настроить

### 1. Улей

В `/opt/hive/.env`:

```sh
# Почта для «Забыли пароль?» (пример для Яндекса; пароль — «пароль приложения», не основной).
SMTP__HOST=smtp.yandex.ru
SMTP__PORT=587
SMTP__USER=hive@yandex.ru
SMTP__PASSWORD=<пароль приложения>
SMTP__FROM=hive@yandex.ru
# Роутеры, которым можно передавать адрес посетителя (необязательно, по умолчанию любые частные адреса):
# HIVE_ROUTER_IPS=192.168.10.1/32 10.10.10.1/32
```

Затем `docker compose up -d` (порт 8088 публикуется сам). В интерфейсе: Настройки → Telegram (привязать чат,
если ещё нет), Настройки → «Почта для восстановления пароля» (придёт проверочное письмо). То же для каждого члена семьи.

Код в Telegram на новом устройстве по умолчанию спрашивается и дома. Если дома он мешает, поставьте
`AUTH__NEWDEVICECODE=External` — тогда только при входе из интернета.

### 2. Роутер: KeenDNS

Дача (Giga) сидит за CGNAT 4G, белого адреса нет, поэтому есть два пути.

**Вариант А, через город (быстрее).** У Giant белый IP, и он видит дачу по туннелю WireGuard (docs/remote-access.md).
1. Giant: «Доменное имя» (KeenDNS) → выбрать имя, режим «Прямой доступ».
2. Там же «Доступ к веб-приложениям домашней сети» → добавить: имя `hive`, устройство/адрес `192.168.10.4`,
   порт `8088`, протокол HTTP. Авторизацию роутера не включать (вход делает сам Улей).
3. Giga, «Межсетевой экран» → Wireguard0: разрешить TCP 8088 с `10.10.10.1` и `192.168.1.0/24` на `192.168.10.4`
   (рядом с правилами из docs/remote-access.md §3).

**Вариант Б, напрямую с дачи.** Giga: KeenDNS в режиме «Через облако», веб-приложение `192.168.10.4:8088`, HTTP.
Работает без белого адреса, но медленнее: фото будут грузиться дольше.

Адрес получится вида `https://hive.<имя>.keenetic.pro`. Сертификат роутер выпускает и продлевает сам.

### 3. Телефон

Открыть адрес, войти (придёт код в Telegram, галочка «Запомнить это устройство»), затем Настройки →
«Приложение на телефоне» → «Установить Улей» (Android: Chrome, Яндекс Браузер; iPhone: Safari → «Поделиться» →
«На экран «Домой»»). Установка требует доверенного HTTPS, поэтому делайте её через адрес KeenDNS.

## Чего не делать

- Не пробрасывать наружу порты 80, 443, 1883 и SSH: наружу смотрит только 8088 через KeenDNS.
- Не включать в KeenDNS доступ к веб-интерфейсу самого роутера, если он не нужен; если нужен — с отдельным сильным паролем.
- Не выдавать учётку без Telegram «на попробовать» — снаружи она всё равно не войдёт, но дома войдёт по одному паролю.
- Обновлять KeeneticOS и образы Улья: дыры в роутере закрывает только производитель.
