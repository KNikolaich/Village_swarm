# Доступ к Улью из города

Схема: дача (Keenetic Giga, 4G за CGNAT) сама поднимает WireGuard-туннель до городского Keenetic Giant, у которого белый IP. Через этот туннель город видит дачные сети.

| | Дача (Giga) | Город (Giant) |
|---|---|---|
| Интерфейс WireGuard | Wireguard0 «toGiant», 10.10.10.2 | Wireguard1 «toGiga», 10.10.10.1, UDP 51820 |
| Сети | 192.168.10.0/24 дом, **172.16.1.0/24 IoT (Улей 172.16.1.2)**, 172.16.2.0/24 детская | 192.168.1.0/24 дом, 10.1.30.0/24, 192.168.3.0/24 |

## 1. Маршруты

Город → дача. На Giant:
- в настройках пира Giga в «Разрешённые подсети» добавить `172.16.1.0/24` (и `192.168.10.0/24`, если нужен домашний сегмент дачи);
- «Маршрутизация» → «Добавить маршрут»: сеть `172.16.1.0/24`, интерфейс Wireguard1.

Дача → город (ответы). На Giga:
- в настройках пира Giant в «Разрешённые подсети» добавить `192.168.1.0/24`;
- маршрут: сеть `192.168.1.0/24`, интерфейс Wireguard0.

## 2. Межсетевой экран на даче

Keenetic по умолчанию считает WireGuard внешним интерфейсом и не пускает с него входящие соединения. На Giga, «Межсетевой экран» → Wireguard0, добавить правила:

| Действие | Источник | Назначение | Протокол / порт |
|---|---|---|---|
| Разрешить | 192.168.1.0/24 | 172.16.1.2 | TCP 22 (SSH) |
| Разрешить | 192.168.1.0/24 | 172.16.1.2 | TCP 443 (интерфейс) |
| Разрешить | 192.168.1.0/24 | 172.16.1.2 | TCP 80 (сертификат /ca.crt) |

Если IoT-сегмент изолирован от остальных («Сегменты» → IoT → запрет доступа в другие сегменты), правила выше на это не влияют: соединения идут из туннеля в сегмент, а не наоборот.

## 3. Проверка из города

```sh
ping 172.16.1.2
ssh kirill@172.16.1.2
```

Интерфейс открывается по `https://172.16.1.2/`. Адрес 172.16.1.2 должен быть в сертификате: передайте его как `install.sh --host 172.16.1.2` при подготовке или просто запустите `install.sh` повторно уже на даче.

## 4. Второй путь: Tailscale (по желанию)

Если туннель Keenetic упал или Giga недоступен, Tailscale на самом RPi даёт независимый вход. Он работает через CGNAT и ничего не требует от роутеров:

```sh
curl -fsSL https://tailscale.com/install.sh | sh
sudo tailscale up --ssh
```

После входа в аккаунт Tailscale RPi доступен с телефона или ноутбука из того же аккаунта по имени `hive`. Ограничение: оператор 4G в режиме белых списков (spec 11.7) режет и этот канал, и сам WireGuard. В таком режиме остаётся только SMS (шаг 17).

## Что не делать

- Не пробрасывать порты Улья в интернет: на даче всё равно CGNAT, а админка не должна торчать наружу (spec 12).
- Не хранить белый IP города в репозитории и документах.
