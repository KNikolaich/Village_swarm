# Нормальный диапазон показаний и цвет числа

У каждого показания (температура, влажность, напряжение...) каждого устройства можно задать **нормальный диапазон**. На экранах Улья число красится:

- **ниже диапазона:** голубой;
- **выше диапазона:** розовый;
- **внутри:** белый, как обычно.

Где видно: плитки зон на обзоре, список «Роя», карточка «Показания» на странице шершня.

## Как задать

Страница шершня → карточка «Показания» → внизу по строке на каждое показание: «Ниже (голубое)» и «Выше (розовое)». Можно указать **только одну границу** (например, «выше 26»). Пустые обе границы убирают диапазон. Менять могут администратор и члены семьи.

Пока диапазон не задан, температура красится по-старому: ниже 0° голубая, выше 28° оранжевая.

## Что это не делает

- Это только цвет на экране: тревог и уведомлений диапазон не создаёт (для тревог есть правила и режим мониторинга).
- Экран 0,42" на шершне монохромный и цвета не показывает.

Хранение: `/api/ranges` (список), `PUT`/`DELETE /api/ranges/{устройство}/{показание}`.
