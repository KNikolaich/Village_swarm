# Плата пропала из Улья: что делать

Сначала посмотрите, что видит Улей: **Настройки → Монитор MQTT** (последние сообщения плат) и **Рой → карточка шершня → Журнал**. Если от платы нет ничего вообще, дальше USB.

## Консоль по USB в приложении Улья

1. Подключите плату к компьютеру проводом (ESP32-CAM: плата с USB-переходником MB; ESP-01: USB-UART адаптер, 3,3 В).
2. Откройте Улей в **Chrome или Edge** (Firefox не умеет Web Serial) по `https://`.
3. **Рой → «Консоль по USB» → «Подключить»**, выберите порт.
4. Вывод платы виден на экране. Кнопка **«Прописать Wi-Fi из Настроек Улья»** записывает в плату сеть и пароль, сохранённые в Настройках, затем **«Перезагрузить плату»**.

Если плата молчит:
- **Батарейная плата спит** (глубокий сон). Перезапустите её: кнопка RESET, подача питания заново или «Сброс» в консоли (не у каждого переходника есть линия RTS). Консоль шлёт в плату перевод строки дважды в секунду, и плата с новой прошивкой после этого не засыпает. На прошивке, где этого ещё нет, надо успеть набрать `awake` в первые 30 секунд после включения.
- **Скорость порта 115200.** В Arduino IDE по умолчанию 9600, и тогда плата «молчит», хотя она пишет. Окончание строки «NL & CR».
- **ESP-01 и другие платы без USB:** TX адаптера к RX платы и наоборот, общий минус, питание 3,3 В отдельным источником (не от адаптера: Wi-Fi потребляет до 300 мА).

## Команды платы

`help` печатает этот же список в консоли.

| Команда | Что делает |
|---|---|
| `show` | что записано: имя, сеть, адрес Улья, число запусков, смена Wi-Fi (`wifi_trying`, `wifi_gave_up`) |
| `set ssid ИМЯ`, `set pass ПАРОЛЬ` | сеть Wi-Fi (значение с пробелами допустимо) |
| `set mqtt АДРЕС[:ПОРТ]`, `set upload http://АДРЕС` | где Улей |
| `set id ИМЯ` | имя шершня (`guard-gate1`) |
| `set mqttuser`, `set mqttpass`, `set token`, `set ntp` | учётные данные и время |
| `enroll http://АДРЕС КОД` | войти в Улей по одноразовому коду из интерфейса |
| `awake` | не засыпать до перезагрузки |
| `reboot` | перезагрузка |
| `factory` | стереть все настройки |

Изменения применяются после `reboot`.

## Как не потерять платы при смене Wi-Fi

- **Выбирайте «Подготовить запасную сеть».** Плата ничего не переключает, а только запоминает новую сеть. Меняйте роутер после того, как в «Событиях» у каждой «запасная сеть сохранена». Так можно сменить и пароль той же сети.
- **«Переключить сейчас»** только для сети, которая уже работает рядом со старой. Сначала на одном шершне, дождитесь «теперь в сети ...», потом остальные.
- Не меняйте сеть на роутере раньше, чем платы получили команду: потерявшая связь плата её не получит, и её придётся лечить по USB.
- Спящие платы команду не получают (она живёт 2 минуты). Включите на них режим «не спит» на время смены или повторите, когда они проснутся.
- Что записано в плате: команда `show` (`wifi_spare` запасная сеть, `wifi_trying` пробуемая, `failed_boots` неудачные запуски подряд). Убрать запасную сеть: `nospare`.
