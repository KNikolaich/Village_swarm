# Что куда писать: `.env` дачи и города

`.env` лежит в `/opt/hive/.env` (создаёт `install.sh`, права только у root: читать через `sudo`). Файл `deploy/.env.example` перечисляет все параметры с комментариями. Ниже то, что нужно двум Ульям, и в каком виде. После любого изменения `.env`: `cd /opt/hive && sudo docker compose up -d` (контейнеры пересоздаются с новыми значениями).

Секреты (пароли, токены, ключи) в репозиторий и в чат не попадают. Ниже стоят заглушки.

## Секреты: в «Настройки → Секреты», а не в `.env`

Токен бота, ключ ассистента, пароль почты и пароль прокси Telegram можно ввести в интерфейсе (только администратор): **Настройки → Секреты**. Они хранятся в базе (`modes`, ключи `secret.*`) в зашифрованном виде (ASP.NET Data Protection), в API только пишутся (виден лишь статус «задан здесь / из .env / не задан»), в журнал и аудит не попадают.

- **Что важнее.** Значение из «Настройки» перекрывает `.env`. Очистили поле: снова действует `.env`. Параметры из `.env` остаются рабочими, как раньше, так что старые установки менять не нужно.
- **Когда применится.** Секреты читаются при старте: после сохранения нажмите «Перезапуск Улья» (карточка ниже).
- **Что остаётся в `.env`.** Секреты, без которых Улей не поднимется до базы: `PG_PASSWORD`, `MQTT_ADMIN_PASSWORD`, `CITY_MQTT_PASSWORD`, `RESTIC_*`, `ZIGBEE_MQTT_PASSWORD`.
- **Где лежат ключи расшифровки.** В папке `keys` рядом с данными: на диске Улья `HIVE_DATA/keys` (по умолчанию `/srv/hive/keys`; в контейнере `DataProtection__KeysPath=/srv/hive/keys`). Эта же папка подписывает куки входа. **Копируйте её вместе с базой**: без неё секреты из дампа не расшифровать (карточка покажет «не прочитать: ключи другие», вводить придётся заново). Ночной бэкап `backup` кладёт `keys` в копию вне Улья (restic), в локальные дампы `backups/db` её нет: настройте `RESTIC_REPOSITORY` (`docs/restore.md`). У дачи и города ключи свои.

## Параметры: в «Настройки → Параметры Улья», а не в `.env`

Обычные (не секретные) параметры тоже можно менять в интерфейсе (только администратор): **Настройки → Улей → Параметры Улья**. Они разложены по разделам: Общие, Вход и безопасность, Мониторинг платы, Дача и город, Ассистент (LLM), Почта, Резервные копии. Хранятся в базе (`modes`, ключи `cfg.*`), в API читаются и пишутся как есть.

- **Что важнее.** Значение из «Настройки» перекрывает `.env`. Кнопка «Сбросить» удаляет его: снова действует `.env`, а если и там пусто, значение по умолчанию. Значения из `.env` работают, как раньше, поэтому старые установки менять не нужно.
- **Когда применится.** Почти всё читается при старте: рядом с параметром стоит пометка «нужен перезапуск», а наверху раздела жёлтый баннер со ссылкой на кнопку «Перезапуск Улья». Исключение: расписание бэкапа (время и день проверки): его контейнер `backup` читает из базы сам раз в минуту, перезапуск не нужен.
- **Что сюда перенесено.**

| Параметр в «Настройки» | Раньше в `.env` |
|---|---|
| Часовой пояс | `HIVE_TIMEZONE` (для API; у контейнеров `backup` и `zigbee2mqtt` часовой пояс из `.env` остаётся запасным) |
| Код при входе с нового устройства | `AUTH__NEWDEVICECODE` |
| Воздух у платы, процессор, диск (пороги) | `HIVE_AIR_WARN_C`, пороги процессора и диска (раньше только в коде) |
| Заметки хранятся в городе | `CLUSTER_NOTES_IN_CITY` |
| Ассистент: модель, адрес API, запросов в сутки | `ASSISTANT__MODEL`, `ASSISTANT__BASEURL`, `ASSISTANT__MAXREQUESTSPERDAY` |
| Почта: сервер, порт, логин, адрес отправителя | `SMTP__HOST`, `SMTP__PORT`, `SMTP__USER`, `SMTP__FROM` |
| Резервные копии: время, день проверки восстановления, куда класть копию вне Улья | `BACKUP_AT`, `BACKUP_VERIFY_DAY`, `RESTIC_REPOSITORY` (пароль `RESTIC_PASSWORD` остаётся в `.env`) |

- **Что остаётся в `.env`.** То, без чего Улей не поднимется до базы или что описывает саму установку: `PG_PASSWORD`, `MQTT_ADMIN_USER/PASSWORD`, `CITY_MQTT_PASSWORD`, `COMPOSE_FILE`, `HIVE_VERSION`, `HIVE_IMAGES`, `HIVE_DATA`, порты, `HIVE_HOSTS`, `HIVE_DEFAULT_SNI`, `CLUSTER_ENABLED`, `CITY_MQTT_HOST/PORT`, `RESTIC_PASSWORD`, `BACKUP_REPO_DIR` и `AWS_*`, `ZIGBEE_*`, `AUTH__BOOTSTRAPADMINPASSWORD`, адреса роутеров. Адрес прокси Telegram (в нём бывает секретный путь) тоже пока в `.env`.

## Общее для обоих Ульев

| Параметр | Что это | Пример |
|---|---|---|
| `COMPOSE_FILE` | какие compose-файлы собираются; ставит `install.sh` | дача `compose.yaml:compose.home.yaml`, город `compose.yaml:compose.city.yaml` |
| `HIVE_VERSION`, `HIVE_IMAGES` | версия образов и их префикс; меняет `update.sh` | `a30158e`, `ghcr.io/knikolaich/village-swarm` |
| `HIVE_DATA` | где на диске данные (БД, фото, бэкапы) | `/srv/hive` |
| `HIVE_TIMEZONE` | часовой пояс; можно сменить в «Настройки → Параметры Улья» | `Europe/Moscow` |
| `HIVE_HOSTS`, `HIVE_DEFAULT_SNI` | адреса, по которым открывают интерфейс (имена в HTTPS-сертификате); определяет `install.sh` | `192.168.10.4,hive.local` |
| `PG_PASSWORD` | пароль БД, создаёт `install.sh` | генерируется |
| `MQTT_ADMIN_USER`, `MQTT_ADMIN_PASSWORD` | логин Улья на своём брокере, создаёт `install.sh` | `hive-api` |
| `AUTH__BOOTSTRAPADMINPASSWORD` | пароль первого пользователя `admin` (только пока нет ни одного пользователя) | заглушка |
| `TELEGRAM__TOKEN` | токен бота; **один и тот же бот у обоих Ульев** | заглушка |
| `TELEGRAM__ENDPOINTS__0__BASEURL` | если Telegram доступен только через ваш прокси, **доменное имя** (сертификат на домен, не на IP) | `https://tg.example.org/секретный-путь` |
| `ASSISTANT__APIKEY` | ключ LLM для голосового помощника; нужен там, где бот работает (на даче, а при падении дачи в городе) | заглушка |
| `SMTP__HOST/PORT/USER/FROM` | почта для «забыл пароль»; можно в «Параметры Улья» (пароль в «Секреты») | по желанию |

## Только дача (`compose.home.yaml`)

```ini
COMPOSE_FILE=compose.yaml:compose.home.yaml
CLUSTER_ENABLED=true
# Адрес городской ВМ ИЗ ДАЧИ (через туннель WireGuard): сюда дача строит мост брокеров
CITY_MQTT_HOST=10.10.10.1
CITY_MQTT_PORT=1883
# Общий секрет двух Ульев: ОДИНАКОВОЕ значение дома и в городе
CITY_MQTT_PASSWORD=<длинный случайный, как в .env города>
# Заметки в городе и порог воздуха теперь в «Настройки → Параметры Улья»;
# CLUSTER_NOTES_IN_CITY и HIVE_AIR_WARN_C в .env остаются запасными значениями
```

## Только город (`compose.city.yaml`)

```ini
COMPOSE_FILE=compose.yaml:compose.city.yaml
# Общий секрет: то же значение, что CITY_MQTT_PASSWORD на даче (install.sh --node city делает его сам)
CITY_MQTT_PASSWORD=<тот же>
# Тот же бот; город опрашивает его, только когда дача молчит
TELEGRAM__TOKEN=<тот же токен>
```

В городе `CLUSTER_ENABLED` не нужен: compose включает кластер сам.

## Что НЕ в `.env`, а в «Настройки» (то, что чаще всего забывают)

Эти два поля нужны дачному Улью, иначе шершни не знают дорогу на город и не могут вернуться:

- **Дача → Настройки → «Запасной брокер (город)»**: адрес брокера **города так, как его видят ШЕРШНИ** дачи (например `192.168.1.3`, порт `1883`). Пустое поле = запасного брокера нет, и Улей стирает его из конфигов шершней.
- **Город → Настройки → «Запасной брокер»**: адрес брокера **дачи** (`192.168.10.4`, порт `1883`). Нужен для шершней, которых город сделал сам.
- **Дача → «Адрес городского Улья для копии фото»**: `https://192.168.1.3` (на самом городе не нужен).

## Проверка, что связка живая

1. На даче `sudo docker compose logs --since 10m mosquitto | tail`: тишина — это норма (брокер пишет только подключения и отключения).
2. В городе вверху страницы нет баннера «дом не отвечает»: город слышит пульс дачи.
3. В «Рое» на обоих Ульях видны `hive-home` и `hive-city` с живыми CPU, ОЗУ, диском.
4. Одноразово: перезагрузите шершня, предпочитающего дачу: он должен появиться на даче.
