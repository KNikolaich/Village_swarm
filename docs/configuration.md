# Что куда писать: `.env` дачи и города

`.env` лежит в `/opt/hive/.env` (создаёт `install.sh`, права только у root: читать через `sudo`). Файл `deploy/.env.example` перечисляет все параметры с комментариями. Ниже то, что нужно двум Ульям, и в каком виде. После любого изменения `.env`: `cd /opt/hive && sudo docker compose up -d` (контейнеры пересоздаются с новыми значениями).

Секреты (пароли, токены, ключи) в репозиторий и в чат не попадают. Ниже стоят заглушки.

## Общее для обоих Ульев

| Параметр | Что это | Пример |
|---|---|---|
| `COMPOSE_FILE` | какие compose-файлы собираются; ставит `install.sh` | дача `compose.yaml:compose.home.yaml`, город `compose.yaml:compose.city.yaml` |
| `HIVE_VERSION`, `HIVE_IMAGES` | версия образов и их префикс; меняет `update.sh` | `a30158e`, `ghcr.io/knikolaich/village-swarm` |
| `HIVE_DATA` | где на диске данные (БД, фото, бэкапы) | `/srv/hive` |
| `HIVE_TIMEZONE` | часовой пояс (журнал, суточные отчёты, бэкап) | `Europe/Moscow` |
| `HIVE_HOSTS`, `HIVE_DEFAULT_SNI` | адреса, по которым открывают интерфейс (имена в HTTPS-сертификате); определяет `install.sh` | `192.168.10.4,hive.local` |
| `PG_PASSWORD` | пароль БД, создаёт `install.sh` | генерируется |
| `MQTT_ADMIN_USER`, `MQTT_ADMIN_PASSWORD` | логин Улья на своём брокере, создаёт `install.sh` | `hive-api` |
| `AUTH__BOOTSTRAPADMINPASSWORD` | пароль первого пользователя `admin` (только пока нет ни одного пользователя) | заглушка |
| `TELEGRAM__TOKEN` | токен бота; **один и тот же бот у обоих Ульев** | заглушка |
| `TELEGRAM__ENDPOINTS__0__BASEURL` | если Telegram доступен только через ваш прокси, **доменное имя** (сертификат на домен, не на IP) | `https://tg.example.org/секретный-путь` |
| `ASSISTANT__APIKEY` | ключ LLM для голосового помощника; нужен там, где бот работает (на даче, а при падении дачи в городе) | заглушка |
| `SMTP__HOST/PORT/USER/PASSWORD/FROM` | почта для «забыл пароль» | по желанию |

## Только дача (`compose.home.yaml`)

```ini
COMPOSE_FILE=compose.yaml:compose.home.yaml
CLUSTER_ENABLED=true
# Адрес городской ВМ ИЗ ДАЧИ (через туннель WireGuard): сюда дача строит мост брокеров
CITY_MQTT_HOST=10.10.10.1
CITY_MQTT_PORT=1883
# Общий секрет двух Ульев: ОДИНАКОВОЕ значение дома и в городе
CITY_MQTT_PASSWORD=<длинный случайный, как в .env города>
# false: заметки остаются на даче, даже когда город предлагает их хранить
# CLUSTER_NOTES_IN_CITY=true
HIVE_AIR_WARN_C=45
```

## Только город (`compose.city.yaml`)

```ini
COMPOSE_FILE=compose.yaml:compose.city.yaml
# Общий секрет: то же значение, что CITY_MQTT_PASSWORD на даче (install.sh --node city делает его сам)
CITY_MQTT_PASSWORD=<тот же>
# Тот же бот; город опрашивает его, только когда дача молчит
TELEGRAM__TOKEN=<тот же токен>
```

В городе `CLUSTER_ENABLED` не нужен: compose включает кластер сам.

## Что НЕ в `.env`, а в «Настройки» (то, что чаще всего забывают)

Эти два поля нужны дачному Улью, иначе шершни не знают дорогу на город и не могут вернуться:

- **Дача → Настройки → «Запасной брокер (город)»**: адрес брокера **города так, как его видят ШЕРШНИ** дачи (например `192.168.1.3`, порт `1883`). Пустое поле = запасного брокера нет, и Улей стирает его из конфигов шершней.
- **Город → Настройки → «Запасной брокер»**: адрес брокера **дачи** (`192.168.10.4`, порт `1883`). Нужен для шершней, которых город сделал сам.
- **Дача → «Адрес городского Улья для копии фото»**: `https://192.168.1.3` (на самом городе не нужен).

## Проверка, что связка живая

1. На даче `sudo docker compose logs --since 10m mosquitto | tail`: тишина — это норма (брокер пишет только подключения и отключения).
2. В городе вверху страницы нет баннера «дом не отвечает»: город слышит пульс дачи.
3. В «Рое» на обоих Ульях видны `hive-home` и `hive-city` с живыми CPU, ОЗУ, диском.
4. Одноразово: перезагрузите шершня, предпочитающего дачу: он должен появиться на даче.
